ABOUT THE PROJECT

Ranking Fraud Detection
in Google Play Store Apps

A student data science project exploring app metadata, rating prediction, and unusual rating/review/install combinations.

Proposed system

The system loads a Play Store app dataset, preprocesses missing values and inconsistent numeric fields, explores app statistics, and applies a Multiple Linear Regression model to estimate app ratings. Transparent heuristic rules highlight a small set of unusual patterns for human review.

Project objectives

  • Prepare app metadata for analysis.
  • Study ratings, reviews, installs, price, and size.
  • Train and evaluate a rating-regression model with R², MSE, and RMSE.
  • Provide an interactive interface for app profile analysis.
  • Clearly document the limitations of fraud inference.

Limitations

The included data is a tiny synthetic practice sample. It has no verified fraud labels, no review timestamps, and no historical ranking changes. The tool cannot confirm fraud. A stronger study needs real sourced data and validation labels or suitable time-series/review-level features.

Technology stack

Python · Pandas · NumPy · scikit-learn · Flask · HTML · CSS · JavaScript · Joblib/Pickle
